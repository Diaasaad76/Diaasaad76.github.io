# Diaa Saad — Portfolio v6 ("Fly-through + Live Room + Workshop Menu")

Plain HTML/CSS/JS, zero build step. Works opened directly from disk (`index.html`) and on any static host. `site-v5` remains untouched.

## Highlights in v6

- **Crisp Studio Portrait → 3D Particle Shatter:** High-resolution portrait on arrival with living rim particles, smoothly dissolving into a 3D perspective tunnel (`rotateY` + micro-parallax + gentle stop settle) as you scroll.
- **1-Minute Subtitled Live Facilitation Clip (`assets/nta-live-1m.mp4`):** Synced English & Arabic captions (`nta-sub-en.vtt` / `nta-sub-ar.vtt` + offline-safe overlay with `[CC]` toggle) showing you coaching a Department Director live at NTA.
- **Interactive Bookable Workshop Menu (`#programmes`):** Filterable 9-course corporate menu (*AI & Digital · Leadership · Trainer & Ops*) where clicking any course pre-fills the Proposal dialog.
- **Dual Executive Downloads:**
  - `assets/Diaa-Saad-Corporate-Profile-2026.pdf`: Branded 1-page corporate training & speaker catalogue for HR/procurement budget sign-off.
  - `assets/Diaa-Saad-Resume-2026.pdf`: Full ATS-clean CV with all typos fixed and Arabic added under Languages.
- **Zero-Lost-Lead Proposal Modal:** `Send by email`, `WhatsApp`, plus 1-click **`Copy brief`** fallback for corporate laptops without a configured mail app.
- **Enhanced Readability & Accessibility:** Stronger WCAG AA+ ink/muted contrast, generous Arabic line-height (`1.64–1.76`), wider desktop card column, smart GPU canvas pause, and semantic `<noscript>` crawler summary.
